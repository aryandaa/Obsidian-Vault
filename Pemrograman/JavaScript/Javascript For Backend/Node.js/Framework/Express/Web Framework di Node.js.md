#programming 
Di Node.js terdapat banyak Web Framework yang dapat Anda gunakan. Masing-masing framework yang ada tentu memiliki kelebihan dan kekurangannya.

### Hapi.js
![](Pemrograman/JavaScript/Javascript%20For%20Backend/Node.js/Framework/Express/img/7.png)
Framework [Hapi](https://hapi.dev/) menyediakan environment yang lengkap untuk mengembangkan web server yang kompleks. Bila menggunakan Hapi, kita tak perlu tools lain untuk menerapkan layer **authentication**, **tokenize**, **cors**, dan lain sebagainya. Kelemahan Hapi adalah abstraksinya yang terlalu jauh dari Node.js native. Kita perlu belajar secara dalam, untuk menguasai framework ini.

### Express
![](Pemrograman/JavaScript/Javascript%20For%20Backend/Node.js/Framework/Express/img/8.png)
[Expressjs](https://expressjs.com/) merupakan web framework tertua dan terpopuler di Node.js saat ini. Express diklaim sebagai _fast, unopinionated, minimalist web framework_ untuk Node.js. Framework ini sangat ringan, mudah diintegrasikan dengan aplikasi web front-end, dan penulisan kodenya tidak jauh beda dengan Node.js native. 

Sesuai dengan klaimnya sebagai framework unopinionated sehingga Express tidak menyediakan struktur atau kerangka kerja yang baku untuk diikuti oleh developer.

Penggunaan framework menjadi pilihan personal. Salah satu faktornya adalah kasus yang hendak Anda hadapi. Ketika ingin membangun server yang sederhana, katakanlah untuk mendukung aplikasi front-end di-_render_ di sisi server, express adalah pilihan yang tepat. 

Express memiliki environment yang cukup luas, ada banyak library, dependencies dan komunitas di luar sana. Kelas ini tidak akan mengajarkan secara dalam tentang API yang ada di Express, melainkan hanya fitur-fitur yang menjadi dasar pembuatan REST API. Jadi, bila Anda ingin mendalami terkait framework Express, sempatkan waktu untuk eksplorasi di [dokumentasi Express](https://expressjs.com/en/5x/api.html) yang disediakan. 

Pada materi selanjutnya kita akan belajar dasar-dasar dari Express dengan cara membuat ulang web server dengan spesifikasi yang sama seperti yang kita lakukan pada latihan sebelumnya.
