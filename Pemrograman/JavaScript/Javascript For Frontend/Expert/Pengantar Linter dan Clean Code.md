#programming 
JavaScript adalah inti dari React. Bila Anda menguasai JavaScript dengan baik, Anda akan mudah memahami React. Namun, belajar JavaScript juga tidak semudah itu, 'kan? Semakin Anda mendalami JavaScript, semakin Anda mengenal “sisi gelap” dari bahasa pemrograman yang satu ini.

Dalam urusan penulisan sintaksis, menurut kami, JavaScript bisa digolongkan dalam bahasa pemrograman yang membingungkan. Contohnya, saat bahasa pemrograman lain menetapkan aturan yang ketat terhadap penggunaan _semicolon_, JavaScript malah membuka ruang untuk developer berdebat soal penggunaannya. 

Contoh lain, ketika hanya ada satu cara dalam pembuatan nilai string pada bahasa pemrograman lain, di JavaScript Anda bisa menggunakan tiga cara yang berbeda, yakni kutip satu, kutip dua, atau _backticks_. Keleluasaan ini membuat developer tidak konsisten terhadap gaya penulisan sintaksis JavaScript yang ujung-ujungnya bisa menimbulkan bugs pada aplikasi. Di JavaScript, semicolon di akhir statement boleh dituliskan ataupun tidak. Hal ini preferensi bagi developer, tetapi tak jarang menjadi perdebatan.

Dalam modul kali ini, kita akan belajar bersama tentang cara menulis kode JavaScript yang lebih baik dengan mengenal style guide, menggunakan linter, dan memahami kaidah-kaidah penulisan kode berdasarkan buku _Clean Code_ karya Robert C Martin. Selain itu, kita juga akan belajar penggunaan Strict Mode pada React selama proses pengembangan agar kita bisa lebih _aware_ terhadap potensi bugs yang terjadi.

Berikut adalah poin pembahasan pada materi kali ini.

- Mengetahui pentingnya menuliskan kode yang konsisten.
- Menggunakan ESLint sebagai JavaScript Linter.
- Mengetahui kaidah penulisan kode yang baik menurut buku _Clean Code_.
- Mengetahui fungsi Strict Mode pada pengembangan aplikasi React.
- Menggunakan Strict Mode dan memperbaiki bugs hasil sorotannya.
