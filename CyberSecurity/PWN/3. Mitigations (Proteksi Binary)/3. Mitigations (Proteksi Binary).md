#roadmap

Sebelum mengeksploitasi binary, kamu harus tahu **proteksi apa yang aktif**. Setiap proteksi mengubah strategi exploit:

| Proteksi | Efek | Bypass |
|---|---|---|
| [[NX]] | Stack tidak bisa dieksekusi | ROP, ret2libc |
| [[ASLR dan PIE]] | Alamat acak tiap run | Leak alamat, partial overwrite |
| [[Stack Canary]] | Crash kalau return address diubah | Leak canary, brute force |
| [[RELRO]] | GOT bisa dibaca saja | GOT overwrite (kalau partial) |
