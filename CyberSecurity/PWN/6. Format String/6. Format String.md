#roadmap

Format string vulnerability terjadi ketika input user dipakai langsung sebagai **format string**: `printf(user_input)` alih-alih `printf("%s", user_input)`. Dari bug kecil ini kita bisa **membaca memory** (leak) dan **menulis memory** (GOT overwrite → RCE).

Urutan Belajar:
1. [[Pengenalan Format String]]
2. [[Format String Read]]
3. [[Format String Write (GOT Overwrite)]]

Ini salah satu bug favorit CTF karena satu bug bisa menghasilkan leak + write sekaligus.
