#roadmap

Buffer Overflow adalah bug paling klasik di PWN: program menulis data melebihi kapasitas buffer, dan data itu menimpa bagian memory lain - termasuk **return address**. Dari situ kita bisa mengendalikan alur program.

Urutan Belajar:
1. [[Pengenalan Buffer Overflow]]
2. [[Offset dan Pattern]]
3. [[Ret2win]]
4. [[Ret2shellcode]]

Praktikkan dengan script di folder `Praktek` (`ret2win.py`, `ret2shellcode.py`) di binary latihan seperti `pwn.college` atau challenge "ret2win" klasik.
