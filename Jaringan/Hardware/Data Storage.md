#jaringan 
***Data storage atau penyimpanan data** adalah media yang digunakan untuk merekam, menyimpan, dan mempertahankan informasi digital agar dapat digunakan kembali pada saat dibutuhkan.

Media penyimpanan dapat menggunakan berbagai teknologi, seperti **magnetik, optik, dan elektronik berbasis semikonduktor**. Contohnya meliputi Hard Disk Drive (HDD), optical disc, Solid-State Drive (SSD), dan flash drive.

Dalam sistem komputer, data sering dibedakan menjadi **input dan output**.

**Input data** adalah data yang diterima oleh sistem komputer untuk diproses. Input dapat berasal dari pengguna melalui keyboard atau mouse, tetapi juga dapat berasal dari berbagai sumber lain seperti sensor, file, jaringan, kamera, atau program lainnya.

**Output data** adalah hasil yang dihasilkan setelah komputer memproses data dan menjalankan instruksi tertentu. Output dapat ditampilkan pada layar, dikirim melalui jaringan, digunakan oleh program lain, atau disimpan kembali ke media penyimpanan.

CPU membutuhkan data dan instruksi untuk melakukan proses komputasi. Namun, data tersebut **tidak harus selalu dimasukkan secara langsung oleh pengguna**.

### Mengapa Komputer Membutuhkan Penyimpanan Data?

Pada masa awal perkembangan komputer, data sering dimasukkan secara manual menggunakan berbagai perangkat input. Memasukkan kembali data secara terus-menerus membutuhkan waktu dan tenaga yang besar.

Komputer kemudian menggunakan memori untuk menyimpan data yang sedang dibutuhkan dalam proses komputasi.

Salah satu jenis memori utama adalah **Random Access Memory (RAM)**. RAM menyimpan data dan instruksi yang sedang digunakan oleh sistem operasi dan program.

RAM memiliki kecepatan akses yang tinggi sehingga CPU dapat memperoleh data dengan cepat. Namun, RAM memiliki keterbatasan penting, yaitu bersifat **volatile**.

Artinya, data yang tersimpan di RAM akan hilang ketika komputer kehilangan daya atau dimatikan.

Komputer juga menggunakan **Read-Only Memory (ROM)**. ROM adalah jenis memori yang digunakan untuk menyimpan data atau instruksi yang tidak sering berubah.

Pada sistem komputer, ROM atau teknologi memori non-volatile sejenis dapat digunakan untuk menyimpan **firmware**, yaitu perangkat lunak tingkat rendah yang membantu perangkat keras melakukan fungsi dasar dan memulai proses kerja sistem.

Walaupun teknologi memori berkembang melalui penggunaan **Dynamic RAM (DRAM)** dan **Synchronous Dynamic RAM (SDRAM)**, RAM tetap dirancang sebagai tempat penyimpanan sementara.

Oleh karena itu, komputer membutuhkan media yang mampu menyimpan data dalam jangka panjang.

Solusinya adalah **data storage atau media penyimpanan data**.

### Fungsi Data Storage

Media penyimpanan memungkinkan data tetap tersimpan meskipun komputer dimatikan.

Sebagai contoh, ketika pengguna menyimpan sebuah dokumen, data tersebut dapat disimpan pada SSD atau HDD. Ketika komputer dimatikan, dokumen tersebut tetap berada di media penyimpanan.

Saat dokumen dibuka kembali, komputer membaca data dari media penyimpanan dan memuat data yang diperlukan ke RAM agar dapat diproses oleh CPU.

Secara sederhana, prosesnya dapat digambarkan sebagai berikut:

**Storage → RAM → CPU**

Ketika sebuah program atau data dibutuhkan, data dibaca dari media penyimpanan dan dimuat ke RAM. CPU kemudian mengambil data dan instruksi yang diperlukan dari sistem memori untuk diproses.

Setelah proses selesai, hasil pengolahan data dapat ditampilkan sebagai output atau disimpan kembali ke media penyimpanan.

Data yang disimpan juga dapat dipindahkan atau dibagikan ke sistem lain melalui jaringan maupun perangkat penyimpanan lainnya.

### Pentingnya Data Storage Saat Ini

Saat ini, kebutuhan terhadap penyimpanan data terus meningkat. Organisasi dan pengguna menghasilkan serta memproses data dalam jumlah yang sangat besar.

Teknologi seperti **Big Data Analytics, Artificial Intelligence (AI), Machine Learning (ML), dan Internet of Things (IoT)** membutuhkan kapasitas penyimpanan yang besar untuk menyimpan dataset dan berbagai informasi yang akan diproses.

Selain menyimpan data, teknologi penyimpanan juga memiliki peran penting dalam melindungi informasi.

Kerusakan perangkat keras, kesalahan pengguna, bencana, serangan siber, atau kegagalan sistem dapat menyebabkan kehilangan data.

Oleh karena itu, organisasi menggunakan sistem **backup dan restore** untuk membuat salinan data dan memulihkannya ketika terjadi kehilangan atau kerusakan.

Dengan demikian, data storage tidak hanya berfungsi sebagai tempat menyimpan informasi, tetapi juga menjadi bagian penting dari pengelolaan, ketersediaan, dan perlindungan data.


### Bagaimana Cara Kerja Data Storage?

Secara sederhana, komputer terhubung ke perangkat penyimpanan baik **secara langsung maupun melalui jaringan**. Perangkat penyimpanan tersebut digunakan untuk membaca data yang sudah tersimpan dan menyimpan data baru agar dapat digunakan kembali di kemudian hari.

Contoh perangkat penyimpanan yang terhubung secara langsung adalah **Hard Disk Drive (HDD)** dan **Solid-State Drive (SSD)** yang terpasang di dalam komputer. Sementara itu, penyimpanan berbasis jaringan memungkinkan komputer mengakses data dari perangkat atau sistem lain melalui jaringan.

Ketika pengguna atau sebuah program membutuhkan data, sistem komputer akan mengirimkan permintaan untuk membaca data dari media penyimpanan. Data yang dibutuhkan kemudian dapat dimuat ke memori dan diproses oleh CPU.

Sebaliknya, ketika data ingin disimpan, sistem akan mengirimkan data tersebut ke perangkat penyimpanan agar direkam dan dapat digunakan kembali meskipun komputer telah dimatikan.

Pada dasarnya, cara kerja penyimpanan data dapat dipahami melalui dua hal utama:

1. **Bentuk atau format data yang disimpan**, yaitu bagaimana informasi direpresentasikan dalam bentuk digital agar dapat dibaca dan diproses oleh komputer.
    
2. **Media atau perangkat penyimpanan yang digunakan**, yaitu teknologi fisik yang digunakan untuk merekam dan mempertahankan data, seperti HDD, SSD, optical disc, atau sistem penyimpanan berbasis jaringan.

Kedua hal tersebut menjadi dasar dari sistem penyimpanan data pada komputer modern.

### Data Storage Devices

Untuk menyimpan data secara permanen, komputer membutuhkan **data storage device atau perangkat penyimpanan data**.

Secara umum, sistem penyimpanan dapat dibedakan berdasarkan cara perangkat tersebut terhubung dan diakses oleh komputer. Dua kategori utamanya adalah **Direct-Attached Storage (DAS)** dan **network-based storage atau penyimpanan berbasis jaringan**.

### Direct-Attached Storage (DAS)

**Direct-Attached Storage (DAS)** adalah perangkat penyimpanan yang terhubung secara langsung ke sebuah komputer atau sistem.

Perangkat tersebut dapat terpasang di dalam komputer atau dihubungkan melalui koneksi langsung seperti USB, SATA, atau teknologi koneksi lainnya.

Contoh DAS meliputi:

- Hard Disk Drive (HDD)
    
- Solid-State Drive (SSD)
    
- USB flash drive
    
- Floppy disk atau disket
    
- Compact Disc (CD)
    
- Digital Versatile Disc (DVD)
    

Sebagai contoh, SSD yang terpasang di dalam laptop merupakan DAS karena perangkat tersebut terhubung secara langsung dengan sistem komputer.

External hard disk yang dihubungkan menggunakan USB juga termasuk DAS.

DAS biasanya digunakan oleh satu komputer atau sistem utama. Karena terhubung secara langsung, DAS dapat memberikan akses penyimpanan dengan performa yang baik dan konfigurasi yang relatif sederhana.

DAS juga dapat digunakan sebagai media backup lokal. Namun, kemampuan berbagi data dengan banyak komputer biasanya lebih terbatas dibandingkan sistem penyimpanan berbasis jaringan.

### Network-Based Storage

**Network-based storage atau penyimpanan berbasis jaringan** adalah sistem penyimpanan yang dapat diakses oleh komputer melalui jaringan.

Berbeda dengan DAS yang terhubung langsung ke sebuah komputer, perangkat penyimpanan berbasis jaringan dapat digunakan oleh beberapa komputer atau pengguna.

Hal ini membuat penyimpanan berbasis jaringan lebih sesuai untuk kebutuhan **berbagi data, kolaborasi, dan pengelolaan penyimpanan secara terpusat**.

Sistem penyimpanan berbasis jaringan juga dapat ditempatkan di lokasi yang berbeda dari komputer pengguna. Hal ini memungkinkan organisasi menggunakannya sebagai bagian dari strategi backup dan perlindungan data.

Dua jenis sistem penyimpanan berbasis jaringan yang umum digunakan adalah **Network-Attached Storage (NAS)** dan **Storage Area Network (SAN)**.

### Network-Attached Storage (NAS)

**Network-Attached Storage (NAS)** adalah perangkat penyimpanan khusus yang terhubung ke jaringan dan menyediakan akses data kepada beberapa komputer atau pengguna.

Secara sederhana, NAS dapat dianggap sebagai **file server khusus untuk penyimpanan data**.

Komputer dapat mengakses file yang tersimpan di NAS melalui jaringan menggunakan protokol berbagi file seperti **SMB (Server Message Block)** atau **NFS (Network File System)**.

Sebuah NAS biasanya memiliki beberapa perangkat penyimpanan seperti HDD atau SSD.

Untuk meningkatkan ketersediaan dan perlindungan terhadap kegagalan perangkat penyimpanan, NAS dapat menggunakan teknologi **RAID (Redundant Array of Independent Disks)**.

RAID menggabungkan beberapa drive dalam satu sistem penyimpanan. Bergantung pada konfigurasi RAID yang digunakan, data dapat disalin atau didistribusikan ke beberapa drive.

Sebagai contoh, jika salah satu drive mengalami kerusakan, sistem RAID tertentu masih memungkinkan data tetap tersedia.

NAS banyak digunakan di rumah, kantor, dan organisasi untuk menyimpan serta berbagi file melalui jaringan.

### Storage Area Network (SAN)

**Storage Area Network (SAN)** adalah jaringan khusus berkecepatan tinggi yang menghubungkan server dengan sistem penyimpanan.

Berbeda dengan NAS yang biasanya menyediakan akses dalam bentuk **file**, SAN menyediakan penyimpanan dalam bentuk **block storage**.

Bagi sistem operasi atau server, penyimpanan yang diberikan oleh SAN dapat terlihat seperti sebuah disk yang terhubung langsung ke sistem.

SAN dapat terdiri dari berbagai perangkat penyimpanan, seperti HDD, SSD, dan flash storage yang terhubung melalui jaringan penyimpanan khusus.

Teknologi seperti **Fibre Channel** dan **iSCSI (Internet Small Computer Systems Interface)** dapat digunakan untuk menghubungkan server dengan sistem penyimpanan SAN.

SAN biasanya digunakan pada lingkungan perusahaan dan pusat data yang membutuhkan kapasitas penyimpanan besar, performa tinggi, serta akses penyimpanan yang dapat dikelola secara terpusat.

### Perbedaan DAS, NAS, dan SAN

**DAS** adalah penyimpanan yang terhubung langsung ke sebuah komputer.

**NAS** adalah penyimpanan berbasis jaringan yang menyediakan akses terhadap file.

**SAN** adalah jaringan penyimpanan khusus yang menyediakan akses terhadap block storage kepada server.

Secara sederhana:

**DAS → Direct Storage**

Komputer terhubung langsung ke perangkat penyimpanan.

**NAS → File Storage melalui Network**

Beberapa komputer mengakses file melalui jaringan.

**SAN → Block Storage melalui Storage Network**

Server mengakses penyimpanan seolah-olah menggunakan disk yang terhubung ke sistem.


## Jenis-Jenis Perangkat dan Sistem Penyimpanan Data

#### 1. SSD dan Flash Storage

**Flash storage** adalah teknologi penyimpanan yang menggunakan **flash memory** untuk menyimpan data.

Sebagian besar **Solid-State Drive (SSD)** modern menggunakan flash memory sebagai media penyimpanannya. Oleh karena itu, istilah **flash storage** dan **SSD** sering digunakan secara bergantian, meskipun secara teknis flash memory merupakan teknologi yang digunakan di dalam SSD.

Berbeda dengan **Hard Disk Drive (HDD)** yang menggunakan piringan magnetik dan komponen mekanis yang berputar, SSD **tidak memiliki bagian yang bergerak (moving parts)**.

Karena tidak menggunakan komponen mekanis, SSD memiliki beberapa keunggulan, antara lain:

- Kecepatan baca dan tulis yang lebih tinggi.
    
- Waktu akses (_latency_) yang lebih rendah.
    
- Lebih tahan terhadap guncangan.
    
- Konsumsi daya yang lebih rendah.
    
- Operasi yang lebih senyap.
    
Karakteristik tersebut membuat SSD menjadi media penyimpanan utama pada banyak komputer modern.

---

#### 2. Hybrid Storage

**Hybrid storage** adalah sistem penyimpanan yang menggabungkan **SSD** dan **HDD** dalam satu infrastruktur penyimpanan.

SSD menawarkan kecepatan akses yang sangat tinggi, sedangkan HDD menyediakan kapasitas penyimpanan yang besar dengan biaya yang lebih rendah.

Dengan menggabungkan keduanya, sistem dapat menyimpan data yang sering diakses pada SSD agar lebih cepat, sementara data yang jarang digunakan dapat disimpan pada HDD untuk menghemat biaya.

Pendekatan ini memberikan keseimbangan antara **performa**, **kapasitas**, dan **efisiensi biaya**.

---

#### 3. Cloud Storage

**Cloud storage** adalah layanan penyimpanan data yang menggunakan server milik penyedia layanan (_Cloud Service Provider_ atau **CSP**) yang berada di lokasi lain dan dapat diakses melalui internet atau jaringan khusus.

Pengguna tidak perlu memiliki server penyimpanan sendiri karena seluruh infrastruktur dikelola oleh penyedia layanan.

Beberapa penyedia layanan cloud yang terkenal antara lain:

- Google Cloud
    
- Microsoft Azure
    
- IBM Cloud
    
- Amazon Web Services (AWS)
    

Penyedia layanan bertanggung jawab mengelola server, menjaga keamanan sistem, melakukan pemeliharaan, serta memastikan data tetap tersedia ketika dibutuhkan.

Cloud storage menawarkan beberapa keuntungan, seperti:

- Kapasitas yang mudah ditingkatkan (_scalable_).
    
- Biaya awal yang lebih rendah.
    
- Dapat diakses dari berbagai lokasi.
    
- Tidak perlu mengelola perangkat keras sendiri.
    

---

#### 4. Hybrid Cloud Storage

**Hybrid cloud storage** menggabungkan penyimpanan **private cloud** dan **public cloud**.

Dengan pendekatan ini, organisasi dapat menentukan lokasi penyimpanan yang paling sesuai untuk setiap jenis data.

Sebagai contoh:

- Data yang bersifat rahasia atau memiliki regulasi ketat dapat disimpan pada **private cloud**.
    
- Data yang lebih umum atau kurang sensitif dapat disimpan pada **public cloud**.
    

Beberapa organisasi juga menggunakan hybrid cloud untuk menambah kapasitas penyimpanan internal ketika kebutuhan penyimpanan meningkat.

---

#### 5. Backup Storage dan Backup Appliances

**Backup storage** adalah sistem penyimpanan yang digunakan untuk membuat salinan data sebagai cadangan.

Backup dilakukan agar data dapat dipulihkan kembali apabila terjadi:

- Kerusakan perangkat keras.
    
- Kesalahan pengguna.
    
- Serangan siber, seperti ransomware.
    
- Kegagalan sistem.
    
- Bencana alam.
    

Perangkat yang digunakan sebagai media backup dapat berupa:

- HDD
    
- SSD
    
- Tape Drive
    
- Server khusus backup
    

Backup biasanya dilakukan secara berkala sehingga tersedia salinan data terbaru yang dapat digunakan saat proses pemulihan (_restore_).

Selain menggunakan perangkat sendiri, banyak penyedia layanan cloud juga menyediakan layanan **Backup as a Service (BaaS)**.

Pada layanan ini, data cadangan disimpan pada server milik penyedia layanan cloud sehingga organisasi tidak perlu membangun infrastruktur backup sendiri.

BaaS menawarkan beberapa keuntungan, seperti biaya yang lebih rendah, kapasitas penyimpanan yang mudah ditingkatkan, serta kemudahan dalam proses pencadangan dan pemulihan data.



## Bentuk-Bentuk Data Storage

Secara umum, data dapat disimpan dalam tiga bentuk utama, yaitu **file storage**, **block storage**, dan **object storage**. Perbedaannya terletak pada cara data diorganisasi, dikelola, dan diakses.

---

### 1. File Storage

**File storage** atau **penyimpanan berbasis file** adalah metode penyimpanan yang paling umum digunakan pada komputer pribadi.

Pada metode ini, data disimpan dalam bentuk **file**, kemudian file tersebut dikelompokkan ke dalam **folder**, dan folder disusun dalam struktur bertingkat yang disebut **direktori (directory)** dan **subdirektori (subdirectory)**.

Contohnya:

```text
D:
│
├── Kuliah
│   ├── Semester 4
│   │   ├── Proposal.pdf
│   │   └── Presentasi.pptx
│
├── Foto
│   ├── Liburan.jpg
│   └── Keluarga.png
```

Sistem operasi seperti Windows, Linux, dan macOS menggunakan metode ini agar pengguna dapat mengelola file dengan mudah.

File storage sangat cocok digunakan untuk:

- Dokumen
    
- Foto
    
- Video
    
- Musik
    
- File aplikasi
    
- Data pengguna sehari-hari
    

---

### 2. Block Storage

**Block storage** adalah metode penyimpanan yang membagi data menjadi sejumlah **block** berukuran tetap.

Setiap block memiliki **alamat atau identitas unik**, sehingga sistem dapat membaca maupun menulis block tertentu tanpa harus mengakses keseluruhan file.

Berbeda dengan file storage, block storage **tidak mengenal konsep folder atau nama file**. Sistem operasi bertugas menyusun block-block tersebut menjadi file melalui **filesystem** seperti NTFS, ext4, atau XFS.

Karena aksesnya sangat cepat dan efisien, block storage banyak digunakan pada:

- Database
    
- Virtual Machine (VM)
    
- Server
    
- Storage Area Network (SAN)
    
- Sistem yang membutuhkan performa tinggi
    

---

### 3. Object Storage

**Object storage** adalah metode penyimpanan yang menyimpan data dalam bentuk **object**.

Setiap object terdiri dari tiga bagian utama:

- Data (isi file).
    
- Metadata (informasi tentang data, misalnya ukuran, tanggal, jenis file, atau atribut lainnya).
    
- Unique Identifier (ID unik yang digunakan untuk mengakses object tersebut).
    

Berbeda dengan file storage, object storage **tidak menggunakan struktur folder tradisional**. Sebagai gantinya, setiap object diidentifikasi menggunakan ID unik.

Object storage dirancang untuk menangani **unstructured data**, yaitu data yang tidak memiliki struktur tetap atau sulit disimpan dalam tabel database relasional.

Contohnya meliputi:

- Foto
    
- Video
    
- Audio
    
- Email
    
- Halaman web
    
- Dokumen
    
- Data sensor IoT
    
- Konten media lainnya
    

Karena mampu menangani data dalam jumlah sangat besar, object storage banyak digunakan pada layanan cloud modern.

Layanan seperti **Amazon S3**, **Google Cloud Storage**, dan **Azure Blob Storage** merupakan contoh implementasi object storage.

Object storage juga banyak digunakan untuk:

- Penyimpanan file cloud.
    
- Backup.
    
- Arsip data.
    
- Big Data.
    
- Machine Learning.
    
- Aplikasi cloud-native.
    

---

### Perbandingan File Storage, Block Storage, dan Object Storage

| Jenis              | Cara Menyimpan Data                | Kelebihan                                          | Contoh Penggunaan                   |
| ------------------ | ---------------------------------- | -------------------------------------------------- | ----------------------------------- |
| **File Storage**   | File dan folder                    | Mudah digunakan dan dikelola                       | Komputer pribadi, dokumen, foto     |
| **Block Storage**  | Block data berukuran tetap         | Sangat cepat dan berperforma tinggi                | Database, Virtual Machine, SAN      |
| **Object Storage** | Object dengan metadata dan ID unik | Sangat mudah diskalakan untuk data berukuran besar | Cloud Storage, Backup, Big Data, AI |
